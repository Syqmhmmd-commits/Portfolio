## 📖 Tentang

Portfolio pribadi yang menampilkan siapa saya, apa yang saya kerjakan, dan project-project open source saya. Fokus di **kernel development** untuk perangkat Android dan **tools CLI** yang berguna.

## ✨ Fitur

- 🎨 **Dark terminal vibe** — tema gelap dengan aksen hijau mint
- ⌨️ **Typing animation** di hero section
- 🖱️ **Cursor glow effect** — ikutin pergerakan mouse
- 📊 **Scroll progress bar** di atas halaman
- 🔢 **Counter animation** — angka naik dari 0 saat di-scroll
- ⚡ **Auto-update repo count** — fetch dari GitHub API (dengan cache 1 jam)
- 🎯 **Active link** di navbar saat scroll
- 📱 **Fully responsive** — enak diliat di HP & desktop
- 🌊 **Smooth reveal animation** saat scroll
- ⬆️ **Back to top button**

## 🛠️ Tech Stack

- **HTML5** — struktur
- **CSS3** — styling (custom properties, grid, flexbox, animasi)
- **Vanilla JavaScript** — interaksi (IntersectionObserver, fetch API, localStorage)
- **GitHub Pages** — hosting

Tanpa framework, tanpa build step. Cuma 3 file.
